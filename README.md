# Random Joke Generator Web App

## 📌 Project Description
The Random Joke Generator is a simple web application built using HTML, CSS, and JavaScript.  
It fetches random jokes from an online API and displays the joke setup and punchline on the webpage.  
A button allows users to load a new joke without refreshing the page.

---

## ✨ Features
- Fetches random jokes using a public API
- Displays joke setup and punchline clearly
- Button to load the next joke dynamically
- Uses internal CSS for styling and glow (shine) effects
- Beginner-friendly implementation

---

## 🛠️ Technologies Used
- **HTML** – for structuring the webpage  
- **CSS (Internal CSS)** – for styling and shine effects  
- **JavaScript** – for fetching data and dynamic content update
